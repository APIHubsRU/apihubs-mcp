# MCP-сервер API Hubs

Генерируйте видео, изображения и музыку из Claude Code, Codex и любого
другого MCP-клиента. Один предоплаченный баланс покрывает все модели
[каталога API Hubs](https://apihubs.ru/models) — Veo, Kling, Seedance,
Seedream, GPT Image, Suno и другие.

Сервер размещён у нас, устанавливать и запускать ничего не нужно. Вы входите
в аккаунт API Hubs через OAuth в браузере, поэтому API-ключ не попадает в
файлы настроек.

Подключение и просмотр описаний инструментов и схем параметров доступны без
входа. Для вызова любого инструмента нужен OAuth, в том числе для чтения
каталога. Авторизуйтесь при настройке или используйте клиент, который
запускает вход при ответе HTTP 401 на вызов инструмента.

- Адрес: `https://api.apihubs.ru/mcp` (Streamable HTTP)
- Документация: <https://docs.apihubs.ru/docs/mcp>
- Официальный MCP Registry: `io.github.APIHubsRU/apihubs`

## Подключение

### Claude Code

```sh
claude mcp add --transport http apihubs https://api.apihubs.ru/mcp
```

Затем введите `/mcp` в Claude Code и пройдите авторизацию в браузере.

Или установите сервер как плагин из этого репозитория:

```sh
/plugin marketplace add APIHubsRU/apihubs-mcp
/plugin install apihubs@apihubs
```

### Codex

```sh
codex mcp add apihubs --url https://api.apihubs.ru/mcp
codex mcp login apihubs
```

`codex mcp login` открывает вход в браузере; повторите команду, если Codex
сообщает, что сервер не авторизован.

### Другие клиенты

Совместимые клиенты — удалённый MCP по Streamable HTTP с OAuth и адресом
возврата на loopback или `https` — подключаются к
`https://api.apihubs.ru/mcp`. Сервер сообщает адрес сервера авторизации через
`/.well-known/oauth-protected-resource/mcp`. Cursor пока не подключается: его
адрес возврата использует собственную схему, которую сервер авторизации не
принимает.

## Инструменты

| Инструмент          | Что делает                                                                                                                      |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `list_models`       | Модели видео, изображений и музыки с ценой «от»                                                                                 |
| `get_model`         | Описание, полная таблица цен, параметры и пример запроса                                                                        |
| `estimate_cost`     | Точная цена запроса для вашего аккаунта до запуска                                                                              |
| `create_generation` | Запускает генерацию и списывает её цену с баланса; необязательные ограничитель `maxCostUsd` и ключ идемпотентности              |
| `create_upload_url` | Подписанная PUT-ссылка для входного файла; загрузите байты методом PUT и передайте полученный `publicUrl` в `create_generation` |
| `get_task`          | Статус и ссылки на результат; может ждать завершения до 30 секунд                                                               |
| `list_generations`  | Ваши последние генерации                                                                                                        |
| `get_account`       | Текущий баланс и ссылка на пополнение                                                                                           |

Инструментам чтения нужно право `mcp:read`; `create_generation` и
`create_upload_url` запрашивают `mcp:generate`, которое позволяет клиенту
тратить ваш баланс, — задайте `maxCostUsd`, чтобы ограничить цену одного
запроса. Отключить клиента можно в любой момент в личном кабинете API Hubs.

## Пример

> Сделай 5-секундное вертикальное видео: бумажный кораблик плывёт по
> дождливой улице. Возьми самую дешёвую модель с форматом 9:16 и уложись
> в $0.50.

Агент просматривает модели, оценивает стоимость, запускает генерацию с
ограничителем `maxCostUsd` и возвращает ссылку на видео, когда задача
завершится.
